# norebo.online

Статический сайт **NOREBO Sound Lab**: бинауральный плеер и лаборатория гуциня. Оба приложения существуют как самостоятельные single-file HTML-страницы без сборки, внешних зависимостей и сетевых запросов.

## Страницы

- `index.html` — бинауральный плеер: частоты Solfeggio, чакры, таймер, генеративные фоновые инструменты (чаши, стекло, гонг, белый шум).
- `guqin/index.html` — лаборатория гуциня: семь струн, открытая/прижатая струна, флажолет, физическая модель на AudioWorklet, осциллограмма и спектр, сохранение тембра.
- `guqin.html` — редирект со старого адреса на `/guqin/`.

## Локальный запуск

```bash
cd norebo.online
python3 -m http.server 8000
```

Открыть:

- `http://localhost:8000/`
- `http://localhost:8000/guqin/`

Для гуциня нужен `http://` или `https://`, а не `file://`: AudioWorklet не загружается с локального файла.

## Деплой

Сайт рассчитан на GitHub Pages с доменом `norebo.online` (см. `CNAME`). Файл `.nojekyll` отключает обработку Jekyll, чтобы статика отдавалась как есть. После `git push` в `main` GitHub Pages собирает сайт автоматически.

## Принципы

- Одна страница — один файл: CSS и JS встроены, внешних шрифтов и CDN нет.
- Звук синтезируется локально; аудиоданные никуда не отправляются.
- Языки: русский и английский, выбор сохраняется в `localStorage`.
